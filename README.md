# VAYUNI — Where Imagination Comes Alive

**VAYUNI** is a unified, interactive web portal blending modern curiosity with ancient Indian wisdom. Designed with an emerald-and-gold glassmorphic interface, it brings together six core pillars of learning and inspiration in one fast, responsive web app.

## Core Features
- **Quotes & Subhashitams:** Inspiring thoughts alongside traditional Sanskrit verses and meanings.
- **Science:** Bite-sized explanations of everyday physics, space, and natural phenomena with mini home experiments.
- **Discoveries & Inventions:** Key milestones from ancient Indian mathematics (such as *Shunya* / Zero) to modern breakthroughs.
- **Did You Know & Learn a Language:** Daily vocabulary, fun linguistic facts, and multi-language greetings.
- **Spiritual Library (Vignanam Mode):** Read Vedic chants, stotrams, and Bhagavad Gita shlokas with instant script switching across **English, Devanagari, Telugu, and Tamil**, plus a daily Panchangam bar.
- **Fun AI Videos:** Curated AI-generated animated storyboards and educational shorts.
- **Live Search & Filtering:** Instant keyword search across all stotrams, quotes, and science articles.

## Built With
- **HTML5** — Semantic structure (`index.html`)
- **CSS3** — Custom emerald & gold gradients, responsive grid, and glassmorphism (`style.css`)
- **Vanilla JavaScript** — Dynamic category filtering, real-time search, and multi-script text rendering (`script.js`)
